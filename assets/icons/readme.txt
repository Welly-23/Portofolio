FOLDER IKON PORTFOLIO
====================

1. Folder ini disediakan untuk menyimpan file ikon tambahan (.svg, .png, .jpg, dll.) jika Anda ingin memperluas website Anda.
2. Saat ini, semua ikon utama website menggunakan "Inline SVG" di dalam file "index.html". Cara ini dipilih agar ikon dapat berubah warna secara otomatis ketika Anda beralih antara Light Mode dan Dark Mode.
3. Jika Anda ingin menggunakan file gambar ikon kustom, letakkan file di sini dan ganti tag <svg> di index.html dengan tag <img src="assets/icons/nama-ikon.svg">.
