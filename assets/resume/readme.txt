TEMPATKAN FILE CV ANDA DI SINI
==============================

1. Rename file PDF CV Anda menjadi "cv-placeholder.pdf" atau nama lain yang Anda sukai.
2. Letakkan file tersebut di folder ini: c:\Users\USer\Documents\Fortopolio\assets\resume\
3. Jika nama file Anda bukan "cv-placeholder.pdf", sesuaikan nama file tersebut di file "index.html" pada bagian tombol Download CV.
